## Oynama

## Sürüm

v140

Bu sürüm, v139'daki güncel hikâye ve oyun sistemlerini ana sayfaya taşır. Ayarlardan bütün ilerlemeyi JSON olarak yedekleme/geri yükleme, sürüm göstergesi ve çeşitli tutarlılık düzeltmeleri eklenmiştir.
