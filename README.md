# Sınıf Kapışması 🥊

Demir tarafından geliştirilen, tarayıcıda çalışan tek dosyalık 2D dövüş oyunu.

## Oyna

Depo GitHub Pages ile yayımlandığında oyun doğrudan `index.html` üzerinden açılır.

Yerelde çalıştırmak için `index.html` dosyasını tarayıcıda açabilirsin. Bazı tarayıcılar `file://` ile açılan dosyalarda güvenlik uyarıları gösterebilir; GitHub Pages üzerinden çalıştırmak daha temizdir.

## Öne çıkan sistemler

- Hikâye, Sonsuz ve Sonsuz+ modları
- Harita düğümleri: Dövüş, Çifte Dövüş, Olay ve Güç
- Çok sayıda güvenli, riskli ve lanetli güç
- Matematik Etüdü, Beşli Ustalaşma ve Infinity build'leri
- Meta puanı, kalıcı kart paketleri ve kalıcı setler
- Beş seviyeli challenge sistemi
- Sonsuz−, Üs Ustası ve Yol Mühendisi challenge'ları
- Yerel iki oyunculu mod
- Mobil kontroller
- Özel karakter oluşturma

## Kayıtlar

Oyun ilerlemesi tarayıcının `localStorage` alanında tutulur. Tarayıcı verilerini temizlemek, gizli pencere kullanmak veya farklı bir alan adından açmak kayıtların ayrı görünmesine neden olabilir.

GitHub Pages adresine geçildiğinde, daha önce `file://` üzerinden oluşan kayıtlar otomatik taşınmaz. Eski kayıtların korunması gerekiyorsa önce mevcut sürümdeki meta/kayıt değerlerinin yedeği alınmalıdır.
